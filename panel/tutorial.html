آموزش اتصال VPN

⚠️ لطفاً ابتدا لینک کانفیگ خود را از ادمین دریافت کنید. لینک با vless:// شروع می‌شود.

📱 اندروید

v2rayNG (پیشنهادی) ▸
1 اپلیکیشن v2rayNG را از گوگل پلی یا GitHub دانلود و نصب کنید.
2 لینک کانفیگ (vless://...) را کپی کنید.
3 وارد اپلیکیشن شوید. از منوی بالا روی + بزنید و «وارد کردن از کلیپ بورد» را انتخاب کنید.
4 روی دکمه ▶ (اتصال) در پایین صفحه بزنید.
5 اگر پیام دسترسی VPN ظاهر شد، تأیید کنید. ✅
NekoBox ▸
1 NekoBox را از GitHub دانلود کنید.
2 لینک کانفیگ را کپی کنید.
3 در اپ روی + → Import from Clipboard بزنید.
4 دکمه اتصال را بزنید. ✅

🍎 آیفون (iOS)

Streisand (پیشنهادی) ▸
1 اپلیکیشن Streisand را از App Store دانلود کنید.
2 لینک کانفیگ (vless://...) را کپی کنید.
3 وارد اپ شوید. از بالا روی + بزنید و «Add from Clipboard» را انتخاب کنید.
4 روی دکمه اتصال بزنید و دسترسی VPN را تأیید کنید. ✅
V2Box ▸
1 V2Box را از App Store نصب کنید.
2 لینک را کپی کنید.
3 در اپ روی + → Import from Clipboard بزنید.
4 اتصال را بزنید. ✅

💻 ویندوز

v2rayN ▸
1 v2rayN را از GitHub دانلود کنید (فایل v2rayN-windows-64.zip).
2 فایل zip را اکسترکت کنید و v2rayN.exe را اجرا کنید.
3 لینک کانفیگ را کپی کنید.
4 در برنامه از منوی بالا: Servers → Import from clipboard
5 روی سرور راست‌کلیک → Set as active server → سپس از system tray روی آیکون راست‌کلیک → System Proxy → Auto ✅

🍏 مک (macOS)

V2RayXS ▸
1 V2RayXS را از GitHub دانلود کنید.
2 لینک کانفیگ را کپی کنید.
3 از منوبار روی آیکون → Import from Pasteboard
4 سرور را انتخاب و وصل شوید. ✅
💡 اگر مشکلی در اتصال داشتید، لطفاً با ادمین خود تماس بگیرید.
